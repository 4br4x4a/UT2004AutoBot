# UT2004AutoBot

UnrealScript mutators for Unreal Tournament 2004 (offline / standalone only). **Untested: not yet compiled against the real game sources**, so expect API-name fixes on first `ucc make`.

- `AutoBotMutator` tunes stock bot stats
- `AutoBotController` + `WeaponPrefs` custom utility-scored bot brain
- `AutoBotSwapMutator` gives botmatch bots the custom brain
- `AutoPlayMutator` autopilot for your own character (`set Input F8 mutate AutoPlay`)

Install steps: see `make.ini.txt`.
